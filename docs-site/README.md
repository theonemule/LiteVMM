# TinyVisor documentation site

This is a standalone [Eleventy](https://www.11ty.dev/) site. It does not ship to, or run on, a TinyVisor host.

```bash
cd docs-site
npm install
npm run start
```

Open the local URL printed by Eleventy. Use `npm run build` for static output in `_site/`.

Screenshots belong in `src/assets/screenshots/`; see the Interface guide for the required capture checklist and filenames.
